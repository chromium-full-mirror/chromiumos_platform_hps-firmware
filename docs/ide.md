# Using an IDE

The Chromium OS documentation has [instructions for setting up
VS Code](https://chromium.googlesource.com/chromiumos/chromite/+/HEAD/ide_tooling/docs/quickstart.md).

## Python autocompletion

If your editor has IDE features for Python (e.g. vscode with the Python
extension installed), then you should open it with the appropriate environment
variables set. e.g.:

```sh
(source environment; code .)
```
